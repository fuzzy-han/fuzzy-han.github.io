# 影戏 ShadowPlay · 光影皮影解谜

把散落的纸偶，拼回它的影子。

**影戏** 是一款以 Material Design 材质美学为灵魂的光影解谜游戏：
深蓝的戏台上浮着 M3 色彩的纸偶，一盏暖灯在黑暗中缓缓移动——
**「表面、高度、阴影、光」不是装饰，它们就是谜题本身。**

## 开始游戏

```bash
node server.js        # 然后打开 http://127.0.0.1:8123
```

或直接用浏览器打开 `index.html`（单文件、零依赖、离线可玩）。

## 玩法

- **拖动纸偶**，让它的影子落进虚框里
- **拖动白色圆柄**旋转纸偶；选中后按 `R` 也可旋转
- **滚动滚轮 / 点纸偶下方的按钮**：升高纸偶——影子会更大、更远
- **拖动光球**：光往哪走，影往哪逃
- 被**钉住**的纸偶不能移动——它们是灯光的坐标
- 全部影子归位，幕布落下

快捷键：`方向键` 微调 · `R` 旋转 · `E` 升/降 · `H` 提示 · `M` 静音

## 十幕

初光 → 成双 → 远山 → 纸鸢 → 浮生 → 寻光 → 月门 → 月晕 → 叠影 → 终幕

从第一道影开始，到月洞门、海上升明月、人间灯火——难度随幕渐进：
前五幕学习拖/转/升，第六幕起灯光成为核心谜题（钉住的影是灯光的唯一坐标）。

## 设计要点

- **玩法即美学**：影子 = 光 × 高度 × 位置（点光源正交投影），
  升高纸偶影子放大偏移——Material 的「高度」概念直接变成解谜变量
- **磁吸吸附**：接近虚框即归位，配清脆的音效，手感流畅不挫败
- **全程序化渲染**：Canvas 2D，多层烘焙软阴影（无 ctx.filter，全浏览器兼容）
- **WebAudio 合成音效**：无音频文件，吸附/通关/解锁各有音色
- 进度与静音偏好存于 localStorage，支持触屏与键盘
