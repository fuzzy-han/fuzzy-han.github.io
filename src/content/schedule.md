# 课程可用

## 课程进度表

| 周次 | 主题 | 重点内容 |
|------|------|----------|
| 第 1 周 | 环境配置 | 编译器安装、IDE 配置、第一个程序 |
| 第 2 周 | 数据类型 | 变量、常量、基本数据类型 |
| 第 3 周 | 控制流程 | if-else、switch、循环语句 |
| 第 4 周 | 数组与字符串 | 一维数组、二维数组、字符串处理 |
| 第 5 周 | 函数 | 函数定义、参数传递、递归 |
| 第 6 周 | 指针 | 指针基础、指针与数组、指针运算 |
| 第 7 周 | 结构体 | 结构体定义、嵌套、结构体数组 |
| 第 8 周 | 文件操作 | 文件读写、二进制文件 |

## 学习建议

- 每周建议学习时间：10-15 小时
- 完成每周任务后进行自我评估
- 遇到问题及时查阅常见问题或寻求帮助
- 每周复习前一周内容，巩固知识
