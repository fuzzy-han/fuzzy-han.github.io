# 系统介绍

欢迎使用 **AutoOj** 在线评测系统！

## 什么是 AutoOj？

AutoOj 是一个专为 C 语言学习者设计的在线评测系统。它能够自动编译、运行和评测你提交的代码，并给出即时反馈。

## 系统特性

- **即时评测**：提交代码后秒级返回结果
- **详细反馈**：不仅告诉你对错，还会显示错误原因
- **多测试用例**：每道题目包含多个测试用例，全面检验代码
- **学习进度追踪**：记录你的学习轨迹和进步

## 快速开始

1. 阅读本手册了解系统功能
2. 查看日程安排，规划学习进度
3. 了解评分标准，明确学习目标
4. 遇到问题可查看常见问题解答
